# CYBER_FOX Neural Scan
A portable web app for real website security analysis using Mozilla Observatory, SSL Labs, and Gemini AI.

## How to Use
1. Open the app at [Live URL].
2. Enter a domain (e.g., google.com).
3. Click "Executar" for a scan.
4. Toggle "Modo Aprendizado" for explanations.

## Setup
- Add your Gemini API key in the HTML script for AI insights.
- No server needed—runs in the browser.

## Features
- Real scans: SSL certificates, HSTS, CSP, etc.
- AI-powered summaries and insights.
